# Code of conduct

Treat contributors and users respectfully. Welcome different experience levels and
backgrounds. Give specific, constructive technical feedback. Respect privacy and consent.

Harassment, discrimination, threats, doxxing and publishing another person's private
information are unacceptable. Maintainers may remove harmful content, close discussions,
or restrict participation proportionately. Context, impact and repeated behavior matter.

Report concerns to repository maintainers through an available private GitHub channel.
If none is available, request a private channel without disclosing sensitive details in
a public issue. Maintainers should protect confidentiality, hear affected people fairly,
and explain enforcement decisions to the extent privacy permits.
